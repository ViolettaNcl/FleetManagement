# Документация для разработчиков

## 1. Обзор
*FleetManagement* — система управления автопарком на C#, WPF, Entity Framework и SQL Server. Код: `[https://github.com/ViolettaNcl/FleetManagement.git]`.

## 2. Требования
- Windows 10+.
- Visual Studio 2019+ (.NET 6.0+).
- SQL Server/LocalDB.
- NuGet: `EntityFramework`.
- Git.

## 3. Сборка и настройка
1. Клонируйте: `git clone [https://github.com/ViolettaNcl/FleetManagement.git]`.
2. Откройте `FleetManagement.sln` в Visual Studio.
3. Настройте базу:
   - В SSMS создайте `FleetManagementDB`.
   - Выполните [Открыть скрипт базы данных](/script.sql)
   - Проверьте: `SELECT * FROM Users;` (`admin@admin`, `user@user`, пароль `123`).
4. В `App.config` проверьте подключение:
   ```xml
    <connectionStrings>
    <add name="FleetManagementDBEntities"
           connectionString="metadata=res://*/Model1.csdl|res://*/Model1.ssdl|res://*/Model1.msl;
                             provider=System.Data.SqlClient;
                             provider connection string='data source=(localdb)\MSSQLLocalDB;
                             initial catalog=FleetManagementDB;
                             integrated security=True;
                             encrypt=False;
                             MultipleActiveResultSets=True;
                             App=EntityFramework'"
           providerName="System.Data.EntityClient" />
    </connectionStrings>
    ```
5.Установите: Install-Package EntityFramework.

- Соберите: Ctrl+Shift+B, запустите: F5.
- Логины: admin@admin (123), user@user (123).

## 5. Тестирование

- MSTest для AuthenticationService, DriverService, RouteService, VehicleService (используют списки).

- Запуск: dotnet test FleetManagement.Tests/FleetManagement.Tests.csproj.

- Проверьте базу: SELECT * FROM Vehicles;.
