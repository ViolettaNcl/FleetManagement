# Политика безопасности

[English](SECURITY.md) · [Инженерное руководство](docs/engineering/quality.ru.md)

FleetManagement — портфолио-проект, не сертификат промышленной безопасности. Публичное Blazor WASM-демо содержит синтетические данные, не подключается к Backend и не хранит привилегированные credentials. Не вводите реальные персональные или коммерческие данные. Отдельный API предназначен для локальной разработки; публичная эксплуатация требует самостоятельного security/deployment review. В историческом WPF/EF6 остаются проблемы безопасности, включая SHA-256 password hashing и назначение администратора по email.

## Сообщение об уязвимости

Сообщайте приватно через GitHub Security advisories, если включено, либо лично владельцу. Укажите ревизию, воспроизведение на синтетических данных, ожидаемое/фактическое поведение и влияние. Не размещайте пароли, токены, персональные данные, логи с секретами и backup базы в публичных issues. SLA ответа не заявляется.

## Контрмеры современной версии

Identity hashing, роли, короткие bearer-токены, отдельная автоматизация, throttling входа, явный отзыв сессий/ролей, транзакционные блокировки, идемпотентные квитанции, лимиты запросов и аудит снижают риски. Токен консоли хранится в памяти; sign-out не равен отзыву на сервере. Явный отзыв security stamp блокирует последующие HTTP-запросы; существующие hub-соединения и выполняющиеся запросы могут продолжаться. Аудит не является защищённым от подделки compliance-журналом. Публичное демо не подключается к серверу cross-origin.

CI проверяет CodeQL и evidence точной ревизии. Чистый скан не подтверждает безопасность всех зависимостей и конфигурации. Отдельно проверяйте advisories, legacy, runtime-образы и внешнюю доступность.
