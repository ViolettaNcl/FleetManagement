- **[Архитектура](architecture.ru.md)** — Где находится логика, какие инварианты данных? *Для кого: Разработчики, ревьюеры.*

- **[Алгоритмы](algorithms.ru.md)** — Какие математические контракты, сложность и ограничения? *Для кого: Optimization/ML.*
- **[Контракт API](api.ru.md)** — Какие эндпоинты, разрешения и правила повторов? *Для кого: Backend, интеграторы.*

## Политика документации

Это актуальная межкомпонентная точка входа. Исходный код, исполняемые тесты и маркер опубликованной сборки имеют приоритет над описанием. Не переносите исторические утверждения о релизах в текущий отчёт. Обновляйте русскую и английскую версии одним коммитом; имена API и ключи конфигурации не переводите. Ссылайтесь на код вместо дублирования длинных фрагментов. Утверждения о производительности, безопасности и точности ML допускаются только с привязкой к ревизии и воспроизводимой процедуре.
