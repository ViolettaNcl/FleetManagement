# Financial reporting and budget planning

Cost Intelligence calculates completed-trip estimates and occupancy as before. Budget projection uses all valid registered trips departing in the inclusive selected dates, regardless of completion state; the same configurable rates apply. Fixed allowance is one manual amount for the whole period. Projected total = fuel + maintenance allowance + driver time + fixed allowance. Headroom = budget minus projection; negative means projected overspend. This projection includes completed trips, so it must not be added to the completed-trip total. No unregistered demand or actual cash-flow forecast.

Export financial Excel creates a real XLSX locally with four worksheets: Summary (period, assumptions, estimated costs and separately reported recorded maintenance amounts), Vehicle Costs, Maintenance Journal (unknown expense blank with status), and Budget (projected costs and headroom). Values are a snapshot, not live formulas. Numeric decimals and finite doubles are numeric cells; user text is inline string, never interpreted as a formula. No external packages or API keys. No real invoice verification, VAT, fixed-cost breakdown, currency conversion, depreciation, or accounting ledger. The earlier two-sheet operational export remains available.
