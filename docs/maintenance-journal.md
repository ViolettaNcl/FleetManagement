# Maintenance work journal
The local browser journal records completed scheduled service, repair or inspection at the demo clock and current registered odometer. Scheduled service resets the last-service fields. Repair and inspection do not. A blank cost is unknown; zero is an explicit known amount. Costs are entered in EUR, not verified invoices. Notes are limited to 500 characters. The journal is append-only within the interface and limited to 5,000 entries; Reset demo clears it. It is not tamper-proof audit storage.

Active trip assignments, invalid vehicle, duplicate exact record, clock/odometer preceding prior work and invalid costs are rejected. Vehicles with journal history cannot be deleted. After a journal record exists, vehicle editing cannot lower odometer below recorded work or directly change the service date/mileage fields. The existing interval length remains editable. Earlier service fields are preserved without inventing a journal record. The optional MaintenanceEntries property in the existing localStorage snapshot defaults to an empty list for older snapshots. No change to API database schema.

Passport shows records for its selected vehicle. Cost intelligence sums known work costs by work date separately from the estimated trip maintenance allowance. It never adds recorded work expense to that allowance, and unknown amounts remain explicitly unknown. No service appointment scheduling, repair parts inventory, historical backdating, corrections, or server persistence in this version.
