# Search strategy and verification
Research date: 2026-11-26. Initial intent clusters derived from actual product capabilities and public competitor terminology, not measured keyword volumes: [Geotab fleet software](https://www.geotab.com/products/fleet-management-software/), [Wialon fleet tracking](https://wialon.com/ru/vehicle-tracking-system), [Wialon maintenance](https://wialon.com/ru/fleet-maintenance-management), [Wialon delivery](https://wialon.com/ru/delivery-fleet-management). No competitor marketing claims are reused. The semantic map is generated as semantic-map.csv, with separate RU/EN landing pages and unverified search volume. Wordstat, Keyword Planner and Search Console data require access; do not fabricate them.
Static HTML is generated at build time only for the public Pages release. Root is the landing site; /app/ is the interactive WASM demo (noindex,follow). Existing local launchers retain original root. The site's visible text, links and metadata work without JS. Sitemap includes canonical public pages only. Sitemap uses no invented lastmod. Structured data describes website/webpage, not ratings or clients.
Verify the project URL-prefix property at Google Search Console and Yandex Webmaster with owner-provided GOOGLE_SITE_VERIFICATION or YANDEX_VERIFICATION public meta values (GitHub repository Actions variables). Submit https://violettancl.github.io/FleetManagement/sitemap.xml. Root domain robots.txt is controlled outside this project; the project copy is informational. Do not edit other repositories. Check canonical and alternate URLs, crawl status, and index coverage. No guaranteed rankings or indexing date.
Sources: https://developers.google.com/search/help/crawling-index-faq and https://yandex.ru/support/webmaster/ru/indexing-options/sitemap.

The semantic map now includes source and research date columns. JSON-LD includes truthful WebSite/SoftwareApplication descriptions for the public demo and BreadcrumbList for visible breadcrumb trails; no fabricated ratings, reviews or prices.

## V4.2 language handoff
Every public RU/EN page links to the interactive demo with an explicit `lang=ru` or `lang=en` query. The demo validates and consumes that value once, preserves other query parameters, and saves the selected preference locally. Direct app links without this parameter keep the existing preference. The public sitemap continues to exclude the demo. Static-link and actual browser tests cover the handoff and persistence; fresh CI is pending.
