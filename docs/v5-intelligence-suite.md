# V5 Intelligence Suite — development candidate

## User workflows
- Intelligence → Maintenance ensemble lab: train three fixed logistic members on 80% vehicle subsamples, compare with full-cohort single model, select threshold on validation by weighted false negatives (1–10) plus false positives, evaluate on separate 12 test vehicles. Display F1, recall, confusion counts, Brier and five calibration bins. Member min/max are disagreement only, not confidence intervals. The five-feature sensitivity table holds other inputs constant and varies one input in bounded hypothetical intervals; it is not causal attribution. Synthetic labels, no real fleet failure validation, no automatic model promotion. Existing ML.NET and imported CSV workflows remain unchanged.
- Cost Intelligence → Budget sensitivity: fixed registered-trip cohort; hypothetical percent changes in fuel, driver and fixed costs from −50 to +100; estimated maintenance allowance unchanged. No extra trip demand, invoices, or actual cash flow claims.
- Analytics → Vehicle report builder: filter the existing date cohort by service status, search and minimum trip count. Registration required; select the other columns. Preview up to 25 rows; workbook includes all matching rows and period/row-count metadata. XLSX user values are inline text, not formulas.
- Notifications → Operational review rules: set high and medium count thresholds and whether to include medium alerts in the preview queue. All high alerts remain present. Explicit save is browser-local. Preview runs only in the open demo, no external notification, assignment, automatic cancellation or data modification.
- Assistant → operational risk and calendar review: deterministic intent, computed register evidence, no language model or paid API.

## Design and performance
Uses existing dark/light tokens and all existing artwork. New shared analytical panel styling, responsive controls and tables, bilingual labels, keyboard focus and reduced-motion behavior. No new runtime dependency or external service. Core report and economics aggregations now index trips by vehicle and report period instead of repeatedly scanning all trips. No quantitative speedup claim without measured comparison.

## V5.2 integrated evaluation and data portability
The V5.1 candidate 0f68471 had 23 successful check runs and one in progress at inspection, with no reported failure. V5.2 adds ranking metrics computed on the same independent synthetic test cohort; ROC-AUC handles tied scores with half credit, average precision groups tied scores and uses step-wise precision-recall integration (not trapezoidal PR-AUC). Both are shown as unavailable for single-class test cohorts. The validation threshold table shows nine fixed options, false positives, false negatives, weighted cost and the selected option; no final-test threshold tuning. The experiment workbook exports only summary metrics and configuration, not raw telemetry or trained model weights.

Assistant matching is a bounded, normalized full-phrase dictionary, not a generative model or unrestricted semantic search. Explicit suggested navigation is read-only and requires a click. The Help & settings JSON export uses the existing snapshot serializer, including registered vehicles, drivers, trips, maintenance, shifts, reservations and simulation clock; it excludes UI preferences. The file may contain names and notes, is generated locally and does not upload data. Restore/import is not implemented. Calendar vehicle and driver lookup is indexed; a deterministic synthetic diagnostic compares the equivalent naive/indexed grouping with checksum assertions, without a timing gate or field performance claim. Tests cover tied and single-class ranking, workbook content, phrase rejection, indexed calendar reconciliation, browser downloads and accessibility. Fresh exact revision CI is required.
