# Operations workspace refinement
The public browser workspace is data-first: compact header and module intros, line icons, fixed desktop navigation, four operational shortcuts, workload distribution based on the actual local trip register, readiness bars, agenda and alerts before illustration cards. All ten original WebP assets are preserved. The 3D illustration is now a dedicated secondary panel rather than the principal working area. Visual language uses neutral graphite and violet accents, clear borders, compact controls and semantic status colors. Both themes remain available. Vehicle register now supports service status filter and result count, route lab displays the selected algorithm's actual metrics. Existing APIs and business logic are unchanged. Test coverage includes real navigation, filter, reduced motion, all artwork hashes and responsive layouts. Public release remains gated on exact-commit checks and live verification.
